## Executive Summary

**TheSignalCallers** is a data‑driven best‑ball analytics brand that turns pre‑snap reads into post‑draft edges.  This brandbook lays out the core identity—voice, visuals, and experience patterns—so every touch‑point (app, podcast, blog, social) feels unmistakably ours while remaining flexible for future sports verticals.

---

## 1. Brand Essence

### 1.1 Mission

Give fantasy drafters the same real‑time insight an NFL quarterback gets when he diagnoses a defense at the line of scrimmage.

### 1.2 Vision

To become the most trusted signal in the noise of daily fantasy sports, expanding from best‑ball football into multi‑sport predictive analytics.

### 1.3 Values

* **Clarity over clutter** – surface only the metrics that move win‑rates.
* **Open‑source spirit** – publish methods and welcome peer review.
* **User empathy** – design for both spreadsheet ninjas and casual phone drafters.
* **Integrity** – model transparency and responsible gaming principles.

### 1.4 Tagline

> *“Read the coverage. Call the win.”*

## 3. Personality & Voice

Our voice blends **quarterback confidence** with **data‑scientist precision**—think Patrick Mahomes explaining a scatter‑plot.  Copy should be:

* **Authoritative** but never condescending (cf. Apple human‑curated tone examples). ([bigbangcopy.co](https://www.bigbangcopy.co/blog/brand-tone-of-voice-examples?utm_source=chatgpt.com))
* **Conversational**: use contractions, rhetorical questions, vivid verbs.
* **Playful when appropriate**—puns are okay in headlines but reserve analysis sections for straight talk.

### Do‑Say Grid

| Don’t                             | Do                                  |
| --------------------------------- | ----------------------------------- |
| "We obliterate your league‑mates" | "We help you out‑draft the room"    |
| "Our proprietary secret sauce"    | "Our open‑sourced Spike‑Week Model" |

## 4. Visual Identity

### 4.1 Logo & Mark

The primary mark is a stylized quarterback hand under center forming a "▶" play button—suggesting both **signal** and **go**.  A logotype variant (“TheSignalCallers”) uses the *Space Grotesk* font.

**Clear Space Rule:**  Maintain at least *1 ×* the height of the "S" around the mark on all sides to preserve legibility. ([kokolv.medium.com](https://kokolv.medium.com/how-to-design-clear-space-for-a-logo-291359020819?utm_source=chatgpt.com))  Minimum display size is 32 px tall for digital and 12 mm for print.

All text‑to‑background combinations continue to meet WCAG 2.2 AA (4.5:1 normal, 3:1 large). ([webaim.org](https://webaim.org/articles/contrast/?utm_source=chatgpt.com), [w3.org](https://www.w3.org/TR/WCAG22/?utm_source=chatgpt.com))

### 4.3 Typography

* **Primary:** *Inter* (variable; weight 300‑700). Optimized for dashboards and mobile readability. ([datafloq.com](https://datafloq.com/read/typography-basics-for-data-dashboards/?utm_source=chatgpt.com))
* **Secondary:** *Space Grotesk* for headlines and numeric data.
* **Code / Data:** *IBM Plex Mono* for snippets and API examples.

Line length target: 45‑75 characters desktop; 32‑40 mobile.

### 4.4 Imagery & Illustration

* Use all‑22 field diagrams, heat maps, and clean iconography.
* Photography should feature diverse fans using tablets during live drafts.
* Ensure imagery maintains at least 8 % padding from edges to honor clear space rule.

### 4.5 Iconography

Icon set follows a 24 × 24 grid, 2 px stroke, rounded joins.  Symbols reference play‑calling (e.g., stack icon = layered squares).

## 5. Content Ecosystem

Prioritize a focused rollout to align with bootstrapping: Start with a blog/newsletter hybrid as the core stream, amplify lightly via social, and expand to podcast/video only after validating traction.

### 5.1 Blog/Newsletter – **“The Audible”**

* 800–1200 word posts, optimized for featured snippets, sent as weekly emails (e.g., via free tiers of Mailchimp or Substack).
* Code snippets in fenced blocks with inline charts from app data.
* Sections: Top ADP Risers, Model Update, Waiver Signals.

### 5.2 Social Media

Lightweight amplification of blog content:

| Platform    | Cadence            | Format                                 |
| ----------- | ------------------ | -------------------------------------- |
| X (Twitter) | 3× daily in‑season | Stat cards, quick polls                |
| TikTok      | 2 shorts/week      | Draft room reactions, chart explainers |
| Discord     | Real‑time          | ADP bot alerts                         |

Including logo in thumbnails reinforces brand recall. ([cuepodcasts.com](https://www.cuepodcasts.com/post/best-branded-podcasts?utm_source=chatgpt.com))

### 5.3 Podcast – **“SignalCast”** (Stretch Goal)

Launch only if blog gains traction (e.g., 200 subscribers):

* **Artwork**: minimum 3000 × 3000 px, bold mark centered, high contrast for dark mode. ([lowerstreet.co](https://lowerstreet.co/blog/podcast-cover-art?utm_source=chatgpt.com))
* **Intro/Outro**: 8‑second sting using QB cadence + subtle crowd noise (free sound libraries).
* **Episode Structure**: Cold open → Key stat of the week → Guest segment → Rapid‑fire audience Q\&A.

## 6. Product Experience Guidelines

Emphasize low-cost, high-impact UX using free tools like Figma community templates.

### 6.1 UX Principles

* **Insight at a glance** – default screen = live ADP delta heat map.
* **One‑hand mobile use** – thumb‑zone compliant controls. ([medium.com](https://medium.com/%40shreyadesign/how-to-design-a-sports-app-ui-a-step-by-step-case-study-guide-616aae95ffd4?utm_source=chatgpt.com))
* **Accessibility First** – all interactive elements ≥ 44 px; haptic feedback on tap; color‑blind safe palette checked against WCAG contrast ratios. ([moldstud.com](https://moldstud.com/articles/p-best-practices-for-optimizing-mobile-apps-accessibility-and-color-contrast?utm_source=chatgpt.com), [developer.mozilla.org](https://developer.mozilla.org/en-US/docs/Web/Accessibility/Guides/Mobile_accessibility_checklist?utm_source=chatgpt.com))

### 6.2 Design System Tokens

| Token           | Value       |
| --------------- | ----------- |
| `--radius-card` | 12 px       |
| `--space-m`     | 16 px       |
| `--elev-card`   | 4 px shadow |

Components: StatCard, ADPChart, ExposureToggle, DraftTimer.
